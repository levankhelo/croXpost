================================================================================
                         🏗️ ARCHITECTURE
================================================================================

BACKEND STACK:
  - Language: Python 3.11
  - Framework: FastAPI 0.104.1
  - Database: PostgreSQL 15 (SQLAlchemy ORM)
  - Auth: JWT tokens (python-jose)
  - Password: bcrypt hashing
  - Task Queue: Redis + Celery ready
  - Server: Uvicorn ASGI

FRONTEND STACK:
  - Framework: React 18.2.0
  - Routing: React Router 6.20.0
  - HTTP: Axios 1.6.2
  - Build: react-scripts 5.0.1
  - Styling: Custom CSS (no framework)

DATABASE SCHEMA:
  ├── users (authentication & profiles)
  ├── platform_accounts (OAuth tokens)
  ├── media_files (uploaded content)
  ├── posts (cross-post records)
  └── platform_posts (per-platform results)

API ENDPOINTS: 15+
  ├── /api/auth/* (2 endpoints)
  ├── /api/users/* (2 endpoints)
  ├── /api/media/* (4 endpoints)
  ├── /api/platforms/* (4 endpoints)
  └── /api/posts/* (4 endpoints)

================================================================================
                      🚀 DEPLOYMENT & USAGE
================================================================================

QUICK START:
  $ git clone https://github.com/levankhelo/croXpost.git
  $ cd croXpost
  $ ./start.sh

MANUAL START:
  $ docker-compose up --build
  $ docker-compose exec backend python init_db.py

ACCESS:
  - Frontend: http://localhost:3000
  - Backend API: http://localhost:8000
  - API Docs: http://localhost:8000/api/docs

REQUIREMENTS:
  - Docker & Docker Compose
  - 2GB+ RAM
  - Ports: 3000, 8000, 5432, 6379
